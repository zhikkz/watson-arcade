# 坍缩实验室

张震的不可逆之夜 —— 一款以物理实验楼为舞台的 2D 横版像素 Roguelite 动作游戏（静态网页）。

凌晨的对撞实验出了事故，整栋实验楼像没人观测的波函数一样散开：摆锤、线圈、烧瓶都活了过来。
研究生**张震**要穿过四个实验区，关掉对撞核心里的奇点。每次倒下，实验室都会重新“坍缩”成另一副模样。

> 物理学只是题材。游戏里的每件装备、每条“定理”写的都是实际效果，不需要任何物理知识。

## 怎么玩

直接用浏览器打开 `dist/index.html` 即可（单文件，无需服务器，也可以丢到任何静态托管上）。

| 操作 | 键盘 | 备用键位 | 手柄 |
| --- | --- | --- | --- |
| 移动 | A / D | ← / → | 左摇杆 / 十字键 |
| 跳跃（空中可再跳一次） | K | 空格 / W / ↑ | A |
| 主手攻击 | J | Z | X |
| 副手攻击 | U | X | Y |
| 技能 | I | C | RT / LT |
| 翻滚 / 空中冲刺（无敌，可穿过敌人和矮通道） | L | Shift | B |
| 喝保温杯回血 | Q | H | LB |
| 互动 | E | F | RB |
| 下跳 / 空中下砸 | S + 跳跃 | ↓ + 跳跃 | ↓ + A |
| 暂停 | Esc | P | Start |

矮通道中，翻滚结束后可以低姿左右移动或停下；站在单向平台上时仍可下跳，离开低矮区域后会自动站起。

### 手机 / 平板

触屏设备有一套单独的操作，全部画在游戏画面里，画面本身铺满整个屏幕：

| 操作 | 触屏 |
| --- | --- |
| 移动 | 左下角的摇杆。默认位置固定（底座不动，只有圆钮跟手）；「设置 → 摇杆位置」可改成「跟随手指」（按在左半屏哪里，摇杆就出现在哪里） |
| 主手 / 副手 / 技能 | 右下角三个圆键（红 / 黄 / 紫），键上直接显示当前装备的图标、等级和冷却 |
| 跳 / 滚 | 右下角的「跳」「滚」 |
| 下跳 / 空中下砸 | 摇杆向下 + 跳 |
| 喝保温杯 | 白色小圆键（显示剩余次数） |
| 互动 | 靠近设施或装备时，右侧出现「互动」键 |
| 暂停 / 地图 | 小地图左边的 Ⅱ / 点右上角的小地图 |
| 菜单 | 直接点选；卡片、商店、终端机是「点一下选中，再点一次确定」；右上角有「返回」 |

- **只支持横屏**：竖着拿手机时，画面会自动旋转 90° 变成横屏（不依赖系统的自动旋转开关），把手机横过来握持即可。
- 支持全屏的浏览器（如安卓 Chrome）在点「开始实验」时会进入全屏并锁定横屏；标题画面也有「全屏游玩」。
- 画面宽度会按屏幕比例在 16:9 ~ 20:9 之间自动伸缩，全面屏手机不留黑边。
- 切到后台会自动暂停。

### 存档

存档保存在**本机浏览器**（`localStorage`），不需要服务器；同一个浏览器、同一个网址下再次打开就能接着玩。

| 存什么 | 什么时候存 |
| --- | --- |
| 永久进度：数据库存、永久解锁、图鉴、通关统计、设置 | 一有变化立刻写入 |
| 进行中的一局（存档点）：装备、定理、文献、生命、保温杯、经费、当前区域 | 每进入一个区域自动保存 |

- 暂停菜单里有「**回到标题**」，确认页会提醒本区域内的进度不会保存；存档点已经在进入区域时写好，直接关闭页面也只保留区域入口状态。
- 标题画面出现「**继续 · 区域名**」时可以接着玩：从该区域的**入口**重新开始，带着进入时的状态（区域内打到一半的收获不会保留，和同类游戏的做法一致）。
- 死亡、通关或在暂停菜单「放弃本局」后，这一局的存档点会被删除。
- 「设置 → 存档管理」可查看规则、重试写入或「**重置本游戏进度**」。重置前会列明删除范围：本游戏的永久进度与本局存档点；**游戏设置和其他游戏存档保留**。确认页默认选中取消。
- 「设置 → 恢复默认设置」只恢复音量、画面和触屏偏好，保留游戏进度。
- 写入失败时会明确提示；已有存档仍会尝试读取，本次更改暂存在当前页面中，可在存档管理中重试写入。重新打开可能回到上次成功写入的状态。
- 存档按浏览器与站点来源（协议、域名、端口）隔离，**同一来源的不同路径共享存档**。更换来源、浏览器或清除站点数据后，存档不会跟过去。
- 永久进度与本局存档点在同一个文档中原子写入，避免上传数据或结算时只保存一半。旧版双键存档会自动迁移，写入成功后才清理旧键；读档保留原随机序列。

## 游戏内容

- **流程**：力学实验楼 → 电磁实验室 → 首领「嘟礼·暴君」→ 热学车间 → 量子对撞机 → 最终首领「奇点」。
  每两个区域之间是**茶水间**：饮水机装满保温杯、黑板上三选一领悟“定理”、终端机上传数据并永久解锁新装备。
- **随机关卡**：每局的房间布局、怪物、机关、宝箱和商店都重新生成。校验使用主角实际尺寸、跳跃、攀沿和碰撞，检查奖励、出口及落脚点能否连通；优先移除孤立台阶并重新落放地面生成物、复验，连续失败后才使用同样通过校验的安全布局。主路线不依赖会消失的平台或移动平台。
- **主角张震**：跑、跳、二段跳、滑铲翻滚、攀沿、下砸，素材来自 `assets-src/zhangzhen`。
- **装备**：12 件武器（活动扳手、游标卡尺、傅科摆锤、激光教鞭、音叉、特斯拉拳套、激光笔、莱顿瓶、电磁轨道炮、陀螺飞盘、液氮喷枪、阴极射线管）
  和 7 个技能（特斯拉线圈、干冰手雷、引力阱、薛定谔的猫箱、虫洞、反物质胶囊、麦克斯韦妖），带随机词条与等级。
- **24 条定理**（被动能力）与三类文献（属性成长）。
- **怪物**：招牌怪物**嘟礼**（素材来自 `assets-src/duli`，含待机 / 追击 / 扑击 / 爪击 / 蹲伏全部动作），
  以及 18 种自设计怪物：研究僧、弹簧跳跳、砝码兵、滑块车、摆锤蝠、静电球、特斯拉塔、磁铁蟹、示波器、光子哨兵、
  冻冻、焦耳、瓦特、麦克斯韦小妖、叠加猫、夸克团、幽灵粒子、奇点幼体。游戏内有图鉴。
- **机关**：摆锤、落锤、活塞、电弧、激光、蒸汽、火焰、冰锥、粒子束、弹射板、移动平台、叠加态平台。

存档保存在浏览器的 localStorage 里（永久解锁、图鉴、设置）。

## 项目结构

```
assets-src/        用户提供的原始素材（张震 / 嘟礼，384x320 逐帧 PNG）
tools/
  build_assets.py  生成全部美术 -> src/assets/atlas.png + atlas.json
  gen_chars.py     把原始素材对齐锚点、缩小为游戏内像素精灵
  gen_monsters.py  自设计怪物（代码绘制）
  gen_items.py     武器 / 图标 / 交互物件
  gen_props.py     场景摆设
  gen_tiles.py     各实验区图块
  gen_font.py      位图字体图集（按源码用到的字符生成）
  build.mjs        打包成单文件 HTML
  test/            Playwright 冒烟测试、关卡批量校验、平衡与性能测试
src/
  page.html        页面外壳（只有一张画布；触屏按键画在画布里）
  js/core/         引擎：资源、字体、输入、触屏（touch.js）、音频、存档
  js/game/         玩法：主角、武器、怪物、首领、关卡生成、界面
dist/
  index.html       成品（完整独立网页）
  artifact.html    片段版本（用于 Claude Artifact 发布）
```

## 构建与测试

需要 Node 18+ 与 Python 3（Pillow、numpy）。

```bash
npm install                      # esbuild 与像素字体
python3 tools/build_assets.py    # 美术有改动时重新生成图集
node tools/build.mjs             # 生成 dist/（加 --dev 不压缩）

node tools/test/levels.mjs 200           # 每个区域生成 200 个关卡并校验可达性
node --test tools/test/regressions.mjs   # 低通道脱困、下跳、旧档迁移、原子写入与前端确认
node tools/test/shot.mjs <目录> flow     # 机器人轮换全部装备通关的冒烟测试
node tools/test/arena.mjs                # 各怪物的击杀时间 / 威胁度
node tools/test/dps.mjs                  # 武器与技能的输出对比
node tools/test/physics.mjs              # 跳跃高度、滑铲、攀沿等移动数值
node tools/test/save.mjs [目录]           # 存档：真实关闭 / 重开浏览器，验证继续、清档、损坏存档
node tools/test/mobile.mjs <目录>         # 手机端：真实触摸事件驱动摇杆 / 圆键 / 菜单，横屏、竖屏旋转、平板
```
